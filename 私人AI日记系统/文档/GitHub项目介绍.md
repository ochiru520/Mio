# Mio

[English](GitHub项目介绍_EN.md) · [0.4.0 预览版（待发布）](https://github.com/ochiru520/Mio/releases/tag/v0.4.0) · [当前稳定版 0.3.1](https://github.com/ochiru520/Mio/releases/tag/v0.3.1) · [反馈问题](https://github.com/ochiru520/Mio/issues)

Mio 是 Windows 上的个人 AI 伙伴与 Agent。对话、长期记忆、日记、语音和桌宠共享本地数据；Agent 的工作、学习和生图入口用于持续处理资料、文件、代码及已配置的创作任务。

**本目录准备版本：0.4.0 · 预览版 · Windows x64 · 待发布。** 线上 Latest 仍为 0.3.1，0.4.0 尚未上传；预览版链接是预定发布页，不代表现在已有下载包。普通用户不需要为主程序自行安装 Python 或 Node.js；云端模型需要你自己的 API，可选能力按需配置。

## 从哪里开始

1. 当前可下载 [0.3.1 稳定版](https://github.com/ochiru520/Mio/releases/tag/v0.3.1)。0.4.0 发布后，再从其专属发布页下载 `Mio-0.4.0-Windows-x64-Setup.exe` 及对应 SHA-256 文件，核对后安装。
2. 在首次向导中确认环境、名字与称呼，添加模型供应商。可以先跳过模型配置，稍后到“设置 > 模型与 API”完成。
3. 先试一次对话，再按需进入 Agent 的工作、学习或生图入口。“项目”绑定已有目录或创建新目录；在 Agent“设置 > 执行权限”确认文件、终端和窗口授权。启用云端能力前确认供应商价格。
4. 聊天“设置 > 环境与模型”管理可选组件；“设置 > 数据与隐私”建立完整备份。聊天和 Agent 共享模型供应商、主题与人设，专属设置分别保留。

安装要求：Windows 11 x64 是主要验证环境；桌面主窗口需要 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。模型权重、Genie 运行数据、Mio 音色、QQ/NapCat、自定义角色资产和参考音频不随主安装包提供。

## 可以做什么

| 入口 | 当前能力 |
|---|---|
| 对话 | 多会话，多个模型供应商，Responses / Chat Completions，附件，思考档位，Token 与费用记录 |
| 记忆 | 查看来源、人工编辑与确认、处理冲突、停用和恢复历史版本 |
| 日记 | 每日日记与回顾、周记、月记、成长统计、Markdown 导出；月记显示完整月份和来源日记 |
| Agent 工作 / 学习 / 生图 | 自然语言任务、进展与补充要求、停止和恢复；学习资料与练习；创作需配置生成服务或 ComfyUI 工作流 |
| 项目与成果 | 目录、会话、资料、任务和成果归档；来源与版本；图片及 Office 成果侧栏内容预览 |
| 代码、终端与 Windows 操作 | 授权范围内读写代码、查看差异、运行检查与命令；观察及操作已授权窗口，需对应依赖就绪 |
| 能力与改造 Mio | 版本化技能、受限数据处理工具与面板；验证后启用或回退；匹配源码及开发依赖就绪时构建、预览和应用本地改造候选 |
| 环境与模型 | 检查、安装、验证和卸载受管可选模型；卸载前显示范围，外部复用资源在原位置管理 |
| 桌宠与语音 | 独立 Live2D 窗口，动作和表情，Genie 本地音色，faster-whisper 转写及语音互动 |
| 微信、QQ 与观察 | 配置相应聊天接入；QQ 使用 NapCat / OneBot；按需开启屏幕、窗口及系统声音观察 |
| 数据与更新 | 本地 SQLite、完整备份恢复、迁移检查、签名更新清单和确认安装；0.4.0 在线升级须等待实际发布 |

QQ、主动联系、自动记录、联网和观察等能力需要分别配置。已安装文件、已配置地址、已连接服务和通过真实调用是不同状态；请以界面实际检测结果为准。

“只查看”“帮我做事”“自主执行”均受实际授权约束，自主执行不会扩大权限。本机终端没有系统沙箱；可选隔离终端需要 Docker，不可用时拒绝运行。Windows 操作受软件界面、焦点和环境影响，不能保证操作所有软件。

Office 侧栏展示支持的文字、表格和图片，不完整还原原始排版、图表或动画，不重算 Excel 公式。大文件、损坏及不支持的文件会给出说明。

## 0.4.0 的主要变化（预览版，待发布）

- 工作、学习、生图入口结合项目目录与成果归档，文件和图片可在右侧查看。
- 接入代码、终端与已授权窗口操作，权限档位、全局默认和项目授权持久保存。
- 长任务持久摘要保留完整历史回读；显示上下文估算，断线按原请求核对，未知写入结果不自动重做。摘要可能遗漏细节。
- 技能与受限扩展支持验证、版本和回退；自主改造在独立副本中检查、构建、预览候选，默认确认应用，安装失败或中断有回退处理。主动回退受版本及数据兼容性限制。
- 共享模型、主题和人设，简化预设与输入控件；改善中文执行结果、公开分析展示、图片预览、对比度和窄窗口布局。
- 补齐 FFmpeg 安装检测及 Whisper 系统声音依赖，修复下载校验、跨来源断点和安装进程状态恢复。

完整变化与历史见 [CHANGELOG](../../CHANGELOG.md)、[版本说明](版本说明.md)及[使用与升级指南](使用与升级指南.md)。0.3.0 已下架；0.2.1 及更早版本可先手动安装当前稳定版 0.3.1。发布前在线更新不会提供本次新版本。

## Genie 与 Mio 音色如何获取

两者是独立可选数据包，不内置于本次主程序。环境中心提供“获取与安装”说明、真实 HTTPS 下载源配置及离线包选择，安装前校验包内容。**获取入口或源配置不代表官方默认下载地址已经存在。** 在线获取须有真实可用且匹配的来源；离线安装须先取得对应包。实际公开附件与各自许可决定可获取及可分发范围，本地有包不代表可以公开上传。

## 数据、隐私与费用

数据保存在本机选择的数据目录，升级时沿用原目录。模型密钥通过 Windows DPAPI 加密，只对当前 Windows 用户有效；备份不等于跨机器自动恢复密钥。

使用云端模型、搜索或云端视觉时，完成请求所需的内容会发送给你选择的服务。本地优先不代表全部离线。更新检查只读取发布服务；屏幕、系统声音、QQ 和主动行为可单独关闭，也可使用隐私总控暂停。

公开仓库不包含作者的聊天、日记、私人角色设定、API Key、QQ 登录态、训练音频或私人模型。费用展示依赖供应商可提供的信息，不能替代供应商账单。

## 从源码运行

开发环境：Windows x64、Python 3.10（发布构建使用 3.10.11）、Node.js 22.12+。源码 ZIP 不需要 Git；构建安装器另需 Inno Setup 6。

先构建界面：

```powershell
cd .\澪Agent应用
npm ci
npm run build
```

再启动后端：

```powershell
cd ..\私人AI日记系统\backend
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000/agent-app/`。开发时可在桌面目录运行 `npm run dev`；完整 Windows 构建使用 `构建Windows应用.ps1`。后端只应监听本机，不要直接暴露到公网。

```text
Mio/
├─ 私人AI日记系统/   FastAPI、SQLite、记忆、记录与服务
├─ 澪Agent应用/      Vue、Windows 启动器、更新器与 Live2D
├─ README.md
└─ README_EN.md
```

中文子目录名称保留用于兼容构建和旧路径。公开版本号与私人开发版本号属于不同通道，不按数字大小互相升级。

## 验证与限制

本次相关功能有自动检查、隔离样例和界面验证；仓库提供 Windows CI 检查，命令见 [CONTRIBUTING](../../CONTRIBUTING.md)。这些证据不代表所有实际场景全部通过，也不覆盖所有显卡、声卡或供应商。

QQ、微信及创作、生图、视频仍由用户自测；语音与桌宠本轮免测，未重新做真实运行验收。尚未完成无开发机缓存和工具的干净 Windows 全量首次安装验收。安装包未做 Windows 代码签名；实际发布后请从官方 Release 下载并核对校验文件。
