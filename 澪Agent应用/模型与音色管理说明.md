# 模型与音色怎么换、怎么保留

在设置中打开「模型与功能」。升级 Mio 后，原来的模型和个人音色继续保留；看到推荐模型不代表必须更换。暂时不安装也可以继续聊天。

## 更换本地视觉模型

切到「看懂屏幕和图片」，查看「选择本地视觉模型」。目前支持 Qwen3.5-2B 和旧版 Qwen2.5-VL 3B。

1. 下载想用的模型。下载只安装文件，不会自动切换或删除旧模型。
2. 点击「验证并使用这个模型」。Mio 先用一张合成测试图片检查实际推理；通过后才保存选择，失败会保留原模型。
3. 不放心时可以把旧模型留着，之后再切回。磁盘上保留两套模型，不等于两套都常驻显存。
4. 确认不需要旧模型后，点击「仅删除这个模型」，检查文件范围和预计空间，再确认。当前使用的模型需要先切换，才能删除；其他模型需要的共用文件会保留。

只有旧 3B 的老用户升级后仍使用旧 3B。已经明确选过某个模型时，即使它缺失，也会显示缺失并提供重新下载，不会悄悄改用另一个模型或上传到云端。首次没有任何模型的新用户推荐 2B。

「卸载整个视觉功能」会移除 Mio 独立的运行器、模型库和相关下载缓存，范围比单模型删除大。仅释放内存时使用停止服务，模型文件保留。系统自己安装的 Ollama 不在 Mio 的卸载范围内。

## 更换个人音色

展开「个人音色文件管理」，查看每个音色的引擎、权重版本、语言、缺少文件和可用运行方式。文件齐全只是可以尝试加载；Mio 会在切换时加载并生成一小段不播放的验证音频，成功后才保留新选择。听感请到声音设置试听。

原生 GPT-SoVITS V2、Genie ONNX 和 Anif 加速副本需要各自兼容的文件。不能把 V2、ProPlus、v5 等不同权重直接混用。缺少加速副本时，可以到 Anif 安装面板选择原音色转换；原始训练权重和参考音频会保留。转换副本与电脑及显卡环境相关，换电脑时可能需要重新编译。

老版 Genie 用户即使没有导入原始训练权重，也不会因升级而被要求换声音；已经确认的 ONNX 音色身份可以保留。无法确认身份的档案会提示补齐文件，不会用默认 Mio 冒充。

## 删除音色与转换文件

- **移除音色配置**：从列表移除该档案，原始文件保留。
- **删除独占的 Mio 管理文件**：只处理预览列出的独占原件。其他音色、加速副本引用的文件、硬链接共用文件和外部目录文件会保留。
- **卸载 Anif 加速副本**：在 Anif 安装面板操作，只卸载该功能管理的环境、转换文件与试听，原始个人音色保留。外部安装不由 Mio 删除。

当前默认音色需要先切换到其他音色，才能移除或清理。已登记的 Anif 音色需要先卸载相关加速副本，再移除档案。每次删除都先显示影响和文件范围；被占用时会列出未删除项，不会把部分完成说成全部成功。

切换模型或音色与删除文件是两件事。先试用，保留原选择的回退机会，再自行决定是否清理空间。
