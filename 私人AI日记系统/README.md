# Mio 私人 AI Agent 后端

Mio 是一个本地优先的个人 AI Agent。这个仓库负责 FastAPI 后端、SQLite 记忆与日记、主动消息、QQ/NapCat、桌宠事件、语音、屏幕观察和模型供应商调用。桌面界面位于相邻的 `澪Agent应用` 目录。

用户最终只需安装和打开一个“Mio”桌面应用。项目中的“前端”是嵌入桌面窗口的 Vue 界面，不是需要单独部署或使用的公开网站；FastAPI 只在本机 `127.0.0.1` 提供界面文件和 API。早期日记网页路由暂时保留用于兼容导出与旧入口，新用户统一从 `/agent-app/` 使用完整应用。

## 主要能力

- 多对话窗口、上下文压缩、结构化记忆与可编辑人格
- 每日日记、每日回顾、每周回顾、统计、导出和自动备份
- OpenAI 兼容模型供应商、原生思考档位、实扣费用异步补账
- QQ 私聊与群聊、NapCat 状态诊断和主动消息
- Live2D 桌宠、澪专属 GPT-SoVITS 音色、屏幕与窗口观察
- PDF、DOCX、图片和常见文本附件

## 运行环境

- Windows 11
- Python 3.10 或更高版本（当前发布构建使用 3.10.11）
- 可选：Node.js 22.12+、NapCat、GPT-SoVITS、OBS、本地视觉模型

## 本地启动

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000/agent-app/`。根地址也会进入该界面。`/diaries` 等早期页面仅作为兼容入口，不作为正式产品界面继续扩展。

至少需要在 `backend/.env` 中配置一个 OpenAI 兼容供应商。不要提交 `.env`。模型供应商密钥在应用内新增时使用 Windows DPAPI 加密保存在当前用户的数据目录。

## 高级设置

应用内“设置 > 高级设置”可修改上下文与记忆预算、主动消息、自动日记与回顾、附件限制、图片归档、屏幕回应超时、屏幕历史保留规则、联网时间规则和本地资料路径。设置写入 `数据/运行设置.json`，该文件不会进入 Git。API Key、QQ Token 和 OBS 密码不通过该接口返回或保存。

“设置 > 人格与属性”可编辑身份、关系、说话方式、行为规则和自定义补充。开源版默认人格是中性的私人伙伴与搭档，不包含特定用户姓名或预设恋爱关系；已有安装继续读取本机 `数据/澪属性.json`，不会被默认模板覆盖。新安装默认关闭主动消息、联网查询以及会自动调用模型的日记/回顾任务，用户确认配置和费用边界后再自行开启。

## 首次启动、迁移与隐私

全新数据目录第一次打开会进入六步向导，先只读检查系统、WebView2、数据目录、磁盘、数据库、电脑概况和各项可选能力，再说明本地/云端边界并配置名字、模型和可选自动能力。可选的本地模型、语音、QQ 或观察环境缺失时不会阻止进入应用，检查过程也不会自动下载或启动它们。已有聊天、日记、记忆、人格或供应商配置的安装会自动识别为旧用户，不会被向导阻断或覆盖。

数据库结构由 `schema_migrations` 记录。存在待执行迁移时，正式数据目录会先创建完整备份，再执行版本化迁移。迁移状态和备份均可在“设置 > 数据与隐私”查看。

“暂停敏感能力”会关闭并停止联网搜索、QQ、主动联系、自动日记/回顾/周记、屏幕观察和系统声音；恢复时只还原暂停前已经开启的项目。普通本地浏览、日记、记忆和备份不受影响。详细规则见 [首次启动与数据迁移](文档/首次启动与数据迁移.md) 和 [隐私说明](文档/隐私说明.md)。

## 完整备份与恢复

设置页可创建、导入、下载和恢复完整备份。备份覆盖 SQLite、日记、记忆、角色、运行设置、供应商配置、头像、背景、附件和桌宠设置，并通过 `manifest.json`、文件大小和 SHA-256 校验；不包含 `.env`、日志、缓存、临时画面和备份目录自身。恢复前会自动创建回退备份，恢复后需要重启应用。

供应商密钥使用 Windows DPAPI 密文保存。同一 Windows 用户可随完整备份恢复；换电脑或换 Windows 用户后必须重新填写 API Key。

## 测试

```powershell
cd backend
.\.venv\Scripts\python.exe -m compileall app
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

公开发布前可运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\工具\开源发布检查.ps1
```

该脚本会检查当前工作树密钥、历史风险提示、敏感文件忽略规则、后端测试、前端构建和两套依赖审计。历史命中会阻止发布，不会自动重写 Git 历史。

需要生成不带旧 Git 历史和私人资产的公开源码包时运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\工具\生成开源发布包.ps1
```

脚本会把两个相邻仓库整理到 `开源发布/Mio-source-<版本>`，用中性占位图替代私人角色图片，在干净目录重新安装依赖并执行测试，最后生成 ZIP 和 SHA-256。它不会修改本机完整版资产。

## 数据边界

`数据/`、`.env`、日志、日记、聊天数据库、附件、照片、桌宠运行设置和本地模型均被 `.gitignore` 排除。发布前仍应执行 `git status --short --ignored` 和密钥扫描。
