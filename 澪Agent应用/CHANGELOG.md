# 变更记录

## 0.5.7 - 2026-08-13

- 桌宠对话条增加电话式持续语音聊天：一次接通后持续监听，VAD 自动断句，本地 Whisper 转写，支持用户开口打断澪。
- 电话回复复用桌宠独立上下文与最近屏幕摘要，不保存麦克风原始音频；简单通话优先关闭模型深度思考以降低等待。
- 桌宠对话条支持自由拖动并默认定位在角色头顶，外层背景透明；隐藏对话条会自动挂断和释放临时观察资源。
- 修复 Live2D 动作叠加、联网结果相关性、主窗口无边框缩放和 WebView2 本机麦克风授权。
- 增加电话音频编码、接口生命周期、屏幕上下文、首音频事件和供应商/Live2D/语音预热回归测试。
- 修复覆盖安装误沿用其他安装实例数据目录的问题；升级优先读取当前安装目录配置，静默安装可显式指定数据目录，并清理已移除的 FILI 旧资源。

## 0.5.6 - 2026-08-13

- 桌宠独立对话改为无边框浮动输入条，只显示输入框与发送按钮。
- 双击桌宠切换打开或关闭对话窗口，右键菜单提供相同的开关入口。
- 保留回车发送、Shift+Enter 换行、图片粘贴与 Esc 隐藏。

## 0.5.5 - 2026-08-13

- 桌宠独立对话窗口移除标题、头像、状态和聊天记录，只保留输入框与发送按钮；窗口缩为轻量输入条，打开时不再轮询历史消息。
- 保留桌宠独立上下文、图片粘贴、语音与气泡回复；已粘贴图片数量和发送错误直接显示在输入框提示中。
- Live2D 动作增加冷却与重复抑制，前台窗口变化不再强制播放动作或切换表情。
- 视线跟随改为每帧至多更新一次，同一情绪不重复应用模型表情，避免悬停时配件与表情参数反复叠加。

## 0.5.4 - 2026-08-12

- 联网搜索增加真实诊断和多搜索源容错，模型供应商区分官方 API 与中转站，并兼容不同模型目录端点。
- 桌宠可独立选择对话模型和思考方式，不再影响主应用或 QQ 的模型配置。
- Live2D 导入补齐未登记表情、封面、动作与表情槽位管理，回复情绪可驱动中文或英文命名的模型表情。
- 桌宠独立聊天窗口改为随主应用隐藏预载，双击桌宠时直接显示，并保留独立上下文和图片粘贴。
- 长说话气泡会跟随打字机内容自动滚动，并在语音结束后按设置停留和隐藏。
- GPT-SoVITS 增加后台预热、首音频延迟诊断和流式尾部兼容，减少首次开口与短句播放等待。

## 0.5.3 - 2026-08-12

- 修复中文数据目录配置由安装器按 Windows 本地编码写入后，启动器固定按 UTF-8 读取导致的启动崩溃。
- 启动器兼容 UTF-8 与 GB18030 配置；成功读取旧编码后自动迁移为 UTF-8，无效配置不再导致未处理异常。

## 0.5.2 - 2026-08-12

- 安装向导增加“沿用原有数据”和“创建全新独立数据”，并允许单独选择数据保存位置；全新数据默认放在程序目录旁，不混入程序文件。
- 安装器把数据目录写入当前安装实例；澪启动时优先读取该配置，不再因改变程序安装位置仍固定复用 `D:\澪Agent数据`。
- 保留 `MIO_DESKTOP_STATE_DIR` 环境变量作为最高优先级覆盖，兼容开发和高级用法。

## 0.5.0 - 2026-08-12

### 新增

- 增加五步首次启动向导，覆盖欢迎、角色与称呼、模型状态、隐私能力和完成确认。
- 设置页增加“数据与隐私”，可查看迁移版本、敏感能力状态，并创建、下载、导入和恢复完整备份。
- 前端 API 按对话、日记、记忆、QQ、语音、观察和设置拆分为领域服务，保留一个用户可见的澪桌面应用。
- 增加全新安装与已有数据升级的兼容流程；无模型时仍可完成向导并进入设置。

### 调整

- Vue 继续作为 `澪.exe` 内置界面，不需要用户单独打开网站；Windows 启动器仍自动启动本地 FastAPI 并嵌入 `/agent-app/`。
- 全新安装的屏幕观察、系统声音、联网、QQ、主动联系和自动记录默认关闭，只有用户明确开启后才运行。
- 设置页窄窗口导航补充可访问名称，删除桌宠语音页重复的合成语言设置。
- 版本统一更新为 `0.5.0`，安装程序继续覆盖到 `D:\澪Agent`，用户数据保存在独立数据目录。

### 已知限制

- 真实 QQ 连续登录、DX11/DX12 独占全屏、HDR、双显示器、游戏性能和连续七天自动任务仍需现场或长期验收。
- Live2D 模型、角色图片、音色和训练素材不自动包含在 MIT 授权中，公开分发前必须分别确认许可。
- 现有 Git 历史不作为公开发布物；公开源码使用经过密钥、私人数据和个人资产扫描的无历史发布包。
