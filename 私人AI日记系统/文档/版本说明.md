# Mio 版本说明

## 0.3.1 · 模型管理、记录与界面修复

- 环境中心支持卸载受管 Genie、Mio 音色、Whisper 与本地视觉资源，删除前预览，保护个人素材与共用环境。
- 修复中文 Windows 的 Genie / Whisper 探针编码及 Genie 加载资源路径，失效缓存不再沿用旧就绪状态。
- 修复任务重试后的父任务关联与前端确认状态；失败恢复和结果核对保留明确边界。
- 人工新增和修订的记忆受到保护；沉睡记忆不继续进入上下文；诊断复制只包含允许字段。
- 重整 Agent 首页和紧凑右侧工具栏，统一模型下拉与更新页面，修复周记摘要和空态布局。
- 月记按完整日记月份建立目录，正确显示未总结月份、篇数和来源；不受首页最近 8 篇或当前搜索结果影响。

升级：0.2.1 及更早版本手动安装 0.3.1；带更新器的公开版本可通过签名更新清单升级。保留原数据目录，升级前完成备份。安装包未做 Windows 代码签名。

验证覆盖源码回归、构建、中文路径冻结应用、隔离数据和本机数据保留。跨机器首装、真人语音／QQ 和不同供应商的长期任务仍需更多实际反馈，不宣称所有环境都没有问题。
