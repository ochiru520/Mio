# Mio 使用与升级指南

## 首次安装

从官方 Release 下载 Windows x64 安装程序及对应 SHA-256 文件。PowerShell 可执行 `Get-FileHash -Algorithm SHA256 -LiteralPath <安装程序路径>`，将结果与校验文件对照。运行安装器，选择程序与数据目录；主应用需要 WebView2。安装器不包含所有可选模型，不需要为了聊天先装齐整个环境中心。

首次向导检查环境、设置名字和称呼、配置模型。模型列表为空时可填写供应商提供的模型 ID，并进行实际聊天测试。接口模式优先自动识别；只有供应商明确要求时才选择特定协议。兼容网关不是官方供应商，费用与数据处理由你使用的服务决定。

## 日常使用

在对话中交流；需要执行文件或创作任务时进入 Mio Agent 工作台。任务页区分运行、待确认、失败及结果未知；遇到未知回执先核对服务端，不要连续重试生成。

记录页切换日记、周记、月记和成长报告。月记列出有日记或已有总结的月份；尚未总结时显示篇数并提供生成按钮。自动月记关闭不会删除旧日记，也不会自动补写总结，手动生成会调用所配置的模型。

记忆页可查看依据、修改内容、停用和恢复版本。模型提取的候选仍需根据界面提示确认；手工修订会保留历史证据。

## 可选模型的安装与卸载

到环境与模型中心查看当前状态。安装后再验证，文件存在不等于模型已成功加载。卸载先展示受管路径和范围，再由你确认；共用运行环境、自定义音色、训练素材和私人数据不应随模型删除。应用借用外部安装位置时，应在原工具中管理。

## 从旧版本升级

1. 在“设置 > 数据与隐私”完成完整备份，并记下正在使用的数据目录。
2. 0.2.1 及更早版本先下载 0.3.1 安装器手动升级，选择沿用原数据；不要手动删除 Data。
3. 已支持应用内更新的公开版本，可检查、下载后选择安装并重启。自动下载不等于自动安装。
4. 打开后核对原对话、日记、记忆和模型设置。问题未排除前保留升级前备份。

私人开发版不自动切换到公开版。未配置更新源时会明确提示，应使用对应通道的安装程序；不要只比较版本数字大小。

## 备份、恢复与换电脑

完整备份用于应用内恢复。迁移到另一台电脑前确认备份是否包含所需模型权重；未包含的模型需重新安装。API 密钥与当前 Windows 用户绑定，换电脑或用户后需要重新填写。不要复制一个正在写入的数据库代替完整备份。

## 排查问题

- 无法聊天：核对 API 地址、Key、模型 ID、供应商额度和真实测试结果。
- 找不到月记：查看月份是否已有日记、是否生成过总结以及自动月记开关。
- 模型不可用：使用环境中心“验证”，查看已安装／已配置／已连接的区别。
- 任务失败或结果未知：先查看回执和服务实际结果，再按提示恢复。
- 更新失败：保留错误信息，检查网络、磁盘与下载状态，不手动删除数据目录。

反馈请给出版本、复现步骤和脱敏诊断。不要公开数据库、聊天、日记、密钥、音色或未经处理的日志。QQ 登录、麦克风和第三方服务行为仍需在真实环境验证。
