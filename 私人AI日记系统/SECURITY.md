# 安全说明

## 报告漏洞

请通过 GitHub Security Advisory 私下报告可能泄露密钥、绕过本地权限、执行任意代码或上传隐私数据的问题。不要在公开 Issue 中附上真实 API Key、QQ Token、聊天数据库、日记、截图或日志原文。

## 本地安全边界

- FastAPI 只监听回环地址，并校验回环 `Host`、浏览器同源 `Origin` 与 `Sec-Fetch-Site`；页面禁止被第三方站点嵌入。该门禁用于阻止跨站请求、DNS rebinding 和点击劫持，不承诺隔离同一 Windows 用户下已经执行的恶意本机程序。
- 对话附件只有固定栅格图片允许同源内联；HTML、SVG、脚本、文档和其他附件统一强制下载，并返回 `nosniff` 与沙箱策略，避免附件在 Mio 的本地源内执行。
- 完整备份导入会限制请求体、清单、条目数量和解压总量，并拒绝重复名称、Windows 设备名、NTFS 数据流、路径越界和清单外文件；校验与解压使用流式读写。不要绕过应用直接解压来源不明的备份 ZIP。
- DOCX/XLSX 在解析前限制 Office 容器的内部条目数和展开总量，并拒绝重复或加密条目。上传体积较小不代表解压后的文档一定安全。
- 日记、回顾和周报 Markdown 作为不可信持久内容进行安全渲染；日期和导出 ZIP 条目名必须通过结构化校验。
- 自定义供应商密钥使用 Windows DPAPI，仅能由同一 Windows 用户解密。
- `.env`、SQLite 数据库、运行设置、附件、日志和音色模型不应进入 Git。
- 云端视觉会发送用户选择的截图范围；本地视觉不会上传画面。
- QQ/NapCat、联网搜索和主动消息均应由用户显式配置；隐私总控暂停时会关闭 Mio 后端当前 OneBot 连接、取消待处理消息并停止发送队列，但不会强制结束 NapCat 或 QQ 客户端进程。
- Agent 的本地行动使用受限动作清单，不允许模型任意改写或执行后端代码。

若怀疑密钥已经泄露，应先在供应商后台撤销密钥，再清理 Git 历史和本机日志；仅从当前文件删除并不足够。
