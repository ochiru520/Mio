# 隐私说明

## 本地保存

聊天、日记、记忆、状态、角色属性、设置、附件和备份保存在本机数据目录。当前安装器默认使用程序目录下的 `Data`（例如 `D:\Mio\Data`）；没有可用 D 盘或用户选择其他位置时，可回落到 `%LOCALAPPDATA%\MioAgent` 或自定义目录。

## 可能发送到外部的内容

- 云端对话：当前消息、按上下文预算选取的历史、相关记忆和用户主动添加的附件。
- 联网搜索：搜索词和为回答读取的公开网页内容。
- 云端视觉：用户选择的屏幕、显示器或窗口画面。
- QQ：本地接收 QQ 消息并把回复发送回 QQ；开启图片模型识别时，图片会发送给当前视觉模型供应商。
- 自动日记/回顾/周记和主动联系：生成时会把对应日期或话题的本地上下文发送给当前模型供应商。

本地视觉不会上传画面。系统声音片段只在内存中用于转写，原始音频不保存；如果转写或后续理解使用云端模型，应以该供应商的实际配置和隐私政策为准。

## 隐私总控

“设置 > 数据与隐私 > 暂停敏感能力”会立即：

- 关闭联网搜索、QQ 通道与 QQ 图片上传模型。
- 关闭主动联系、自动日记、自动回顾、周记和夜间收尾。
- 关闭屏幕 AI、系统声音监听和观察语音。
- 停止当前屏幕捕获和系统声音进程。

应用会保存暂停前快照。“恢复原设置”只恢复原本开启的能力，不会把原本关闭的功能打开。普通本地浏览、日记查看、记忆查看和备份仍可使用。

云端普通对话不由总控强制禁用，因为每次发送本身就是用户主动操作；不希望任何内容出机时，不要发送消息，并移除/禁用模型供应商。

## 密钥和发布

应用内供应商密钥使用 Windows DPAPI 保存，不在界面回显。`.env`、数据库、运行设置、日志、日记和附件必须保持 Git ignored。公开源码包不包含本机数据、密钥、音色、训练素材、模型检查点或私人角色图片。
