## 当前审计结论（2026-08-10）

- 当前工作树没有发现真实 API Key 明文，但历史扫描命中 `e545e45`、`ca923fe`、`3027923` 和 `359b874` 等提交；其中包含测试密钥、配置示例或曾经的 Token 配置痕迹。公开前必须逐条人工确认，并选择“建立全新干净公开仓库”或在备份后重写历史。
- 未经明确授权不要直接执行 `git filter-repo`、强制推送或删除旧仓库历史。
- 新安装默认关闭主动消息、联网查询和自动模型任务；现有用户的 `数据/运行设置.json` 继续覆盖默认值。

- 旧 Git 历史不会进入干净源码包，但若直接公开现有仓库，历史凭据风险仍然存在。
