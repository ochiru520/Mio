# Anif 语音使用与分发说明

本文对应 2026-11-02 的本地开发版。模型中心已加入 Anif 图形安装与 V2 音色转换流程，并覆盖到本地 `D:/Mio`。本机独立新环境的下载、八阶段编译、中日发声、启用及卸载已通过，尚未对外发布；旧公开安装包不会自动获得这项功能。

这套适配使用 **AnifLive 推理加速 + GPT-SoVITS V2 配套权重**。Anif 是运行与加速方式，实际声线取决于导入的 V2 音色。原 Mio 的本机适配使用原来两份微调权重；其他用户使用自己的权重，不会自动获得原 Mio 音色。

## 普通用户的操作流程

不需要每个人重新训练声音。可以使用自己训练的音色，也可以获取获准使用的现成 V2 音色。先准备配套的 GPT `.ckpt`、SoVITS `.pth`、一段参考音频、参考音频的准确原文和语言。

1. 在声音设置中选择原生 GPT-SoVITS V2，导入两份权重和参考音频，填写准确原文及语言，保存这个音色。
2. 打开「环境与模型 → 模型与功能 → 让 Mio 说话」，找到 Anif，点击「安装 Anif / 转换自己的音色」。
3. 检查显卡、磁盘空间及音色是否齐备。选择刚才导入的 V2 音色，点击「开始安装并编译」。
4. Mio 下载固定版本的运行环境、上游资源与共享模型，然后在这台电脑上转换并编译八阶段加速引擎。首次下载为多 GB，编译也需要时间，请保持网络和充足磁盘空间；不承诺固定完成时间。
5. 编译后自动执行中文和日语实际发声检查。只有编译完成并通过检查，才提供试听和使用入口；下载完成本身不代表可以发声。
6. 读取中文、日语试听并播放。满意后点击「使用这个音色」，才会注册并切换到新 Anif 音色；准备阶段不改当前语音选择。返回聊天即可播放消息语音。

整个流程是可选功能。没有下载模型、检查未通过或暂时不想配置时，可以直接跳过，继续聊天，之后回到模型中心处理。收起安装面板不会取消后台任务；需要停止时点击「取消准备」。编译阶段没有暂停按钮。

失败后会显示错误，可以检查网络、空间或音色文件后重试。不要把失败状态、文件存在或进度到达某个百分比，当作实际发声成功。

## 电脑要求与速度

当前 Anif 路径需要兼容的 **NVIDIA 显卡与驱动**。AMD、Intel 显卡及 CPU 不走这套加速流程，可跳过并使用其他已支持的语音引擎。安装器使用固定版本依赖；普通用户不需要另外安装 MSVC 编译工具。

原 Mio Anif 运行链及新安装流程已在 RTX 4060 Laptop 8GB 上通过本机独立新环境验收。干净 Windows 电脑和其他显卡尚未验收，不能将本机成功扩大为所有电脑可用。

已有本机运行链的首次加载及预热约 30 秒，驻留后的短句首段音频约 0.3～0.5 秒；长句还受文本处理影响。这些是此前本机测量，不包含首次下载、转换与编译，不是其他电脑的速度保证，也不代表 Anif 对每段文字都快于原生 V2。

界面保留实验标识。自动中日发声检查验证基本推理与音频输出，音色、断句和听感仍需试听；此前五个专用阶段各一组数值对照通过，不等于全部动态形状正式精度认证。

## 换音色与版本兼容

| 音色文件 | 使用方式 |
|---|---|
| GPT-SoVITS V2 配套 `.ckpt` / `.pth` | 在声音设置导入，再通过模型中心为这对权重转换和编译 |
| V2ProPlus / v5 权重 | 不兼容本轮 V2 适配，需要各自兼容的服务与模型 |
| Genie ONNX 音色包 | 使用 Genie 入口，不能作为 V2 原始权重或 Anif 引擎 |

换成另一套 V2 音色，需要为那对权重重新准备专用引擎，完成发声检查后再显式使用。只改音色名称、profile 或参考音，不会替换微调权重。安装页试听与「使用这个音色」始终对应已经编译的任务；在下拉框选了新音色后，应先为新音色编译。

原生 GPT-SoVITS V2 入口继续保留。Anif 效果不满意或运行失败时，可以在声音设置选择已安装可用的原生 V2 或其他引擎。

## 卸载、位置与换电脑

安装页提供「卸载 Anif，释放磁盘」：先展示删除范围和预计空间，再确认卸载。只清理 Mio 管理的 Anif 环境、资源及编译产物，保留用户导入前的原始权重、参考音和其他语音引擎。文件被占用时会提示未完全卸载，可以在停止占用后再次操作。

八阶段清单内部使用相对路径，运行注册会按本机实际位置生成，不要求普通用户填写开发者电脑的路径。但 Python 虚拟环境不能靠直接复制文件夹完成迁移，TensorRT 引擎也受显卡和环境版本约束。

当前更换安装位置的方式是：**保留原始音色 → 卸载受管 Anif → 更改模型位置 → 重新安装并编译**。不要直接搬动虚拟环境或编辑路径后继续使用。更换电脑、显卡或不兼容的运行环境后，需要在目标电脑重新编译并验收。

## 分发与当前验收边界

本地版本已包含：模型中心图形入口、显卡与空间检查、固定版本环境准备、V2 音色八阶段本机编译、中日实际发声验收、试听后显式使用、取消与失败重试、受管卸载。前端流程已做隔离交互及不同窗口宽度检查，完整安装链也已通过本机独立新环境验收；部分固定哈希共享模型复用了本机公开资源，并非干净电脑从零认证。

待完成的分发验收包括：干净电脑网络安装、其他 NVIDIA 显卡、长时间使用与更广的动态形状精度检查。未完成这些检查前，不宣称普遍兼容或正式发布；正式 `D:/Mio` 的覆盖状态以项目最新验收记录为准。

对外应使用不带私人配置和聊天数据的完整 Mio 安装包。音色、基础模型及第三方组件按各自授权提供；不复制开发者的 Data、私人设置或整套私人音色目录。
