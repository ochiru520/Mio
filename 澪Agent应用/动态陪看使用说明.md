# 动态陪看（试用）

打开桌宠，右键选择「陪我看主屏幕（试用）」或已选窗口，即可开始；再次右键可停止。观察页和设置页也能选「动态陪看（试用）」，设置本身不会开始采集。

动态陪看会在本地挑选变化较大的画面，最多把四帧按时间顺序放在一张图里，让当前视觉模型理解前后的变化。静止画面不反复分析，点击手动看一眼则读取最新单张画面。

变化灵敏度可选安静、正常、灵敏。开始观察后持续采集，画面有有效变化就进入下一轮分析，不再等待固定的 30/15/8 秒；静止画面不重复提交。采集和循环检查有正常的处理时间，一轮识图和回答完成后才会处理下一轮，不会并发堆积；模型冷启动仍会更久。

想恢复原方式，选择「单帧观察」并重新开始。模型沿用自己的视觉设置；是否收听电脑声音沿用现有开关。没有配置好模型时可跳过，继续聊天。

这是参考 See Now 动态筛帧思路、独立实现的 Mio 功能。画面文字可能被看错，视觉描述供陪伴使用；本轮未验证完整语音对话延迟。
