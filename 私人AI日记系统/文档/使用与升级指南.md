# Mio 使用与升级指南

## 发布状态与首次安装

本目录是 **0.4.0 预览版待发布候选**。[0.4.0 预定发布页](https://github.com/ochiru520/Mio/releases/tag/v0.4.0)尚未上传，线上 Latest 仍是 [0.3.1 稳定版](https://github.com/ochiru520/Mio/releases/tag/v0.3.1)。当前 Latest 不是 0.4.0 安装包。

版本实际发布后，从对应官方 Release 下载 Windows x64 安装程序及 SHA-256 文件。PowerShell 可执行 `Get-FileHash -Algorithm SHA256 -LiteralPath <安装程序路径>`，对照校验结果后安装。选择程序与数据目录；主应用需要 WebView2。普通用户不需要自行安装 Python 或 Node.js 才能运行主程序，也不需要为了聊天先安装所有可选模型。Windows 11 x64 是主要验证环境；干净 Windows 全量首次安装仍未完成验收。

首次向导设置名字、称呼和模型；也可在“设置 > 模型与 API”稍后配置。模型列表为空时可填写供应商的模型 ID，并进行实际聊天测试。接口模式优先自动识别。兼容网关的费用与数据处理由所用服务决定；云端请求可能产生费用。

## 日常使用与项目

在对话中交流；处理资料、文件或代码时进入 Mio Agent 的“工作”，整理资料和练习使用“学习”，创作图片使用“生图”。创作、生图和视频需要相应服务、ComfyUI 工作流、模型与依赖就绪。入口存在不代表已经安装或连接这些服务。

在“项目”中新建目录或选择已有目录，归集要求、会话、任务、资料和成果。可以查看任务进展、补充要求、停止或继续。任务页区分运行、待确认、失败及结果未知；未知结果先核对回执和实际服务状态，避免连续重试生成或写操作。

点击已归档成果及消息中的成果附件打开右侧预览，可调整侧栏宽度或关闭。Word、Excel、PowerPoint 预览展示支持的文字、表格和图片，不完整还原原版式、图表、批注或动画，不重算 Excel 公式。大文件、损坏文件和不支持格式会给出说明；普通未归档输入附件沿用原查看方式。

长任务会保存上下文摘要，完整对话与工具记录仍可回读。摘要可能遗漏细节；预算不足或摘要失败会提示。上下文占用是估算，不是精确账单。断线按原请求核对后台状态，不自动重复提交；点击停止仍取消执行。

记录页提供日记、周记、月记和成长报告。月记列出有日记或总结的月份；自动月记关闭不会删除旧日记或自动补写总结，手动生成使用所配置模型。记忆页支持查看依据、编辑、停用与恢复版本。

## 设置与执行权限

聊天与 Agent 共享“模型与 API”、主题、人设和表达设置；任务参数及聊天专属设置分别保留。跨窗口读取同一配置。人设预设通过选择、套用和保存生效；公开分析表达只调整模型可提供内容的展示，不补造内部思考。

Agent“设置 > 执行权限”提供“只查看”“帮我做事”“自主执行”。分别确认读取、写入、终端及窗口范围，全局默认可被显式项目配置覆盖。“只查看”阻止修改、终端和键鼠动作；“自主执行”只复用已授权范围，不自动扩大权限。运行时保留停止和确认入口。

本机终端不提供系统沙箱，工作目录无法从系统层阻止命令访问其他位置。可选隔离终端需要 Docker 可用；缺少环境时拒绝运行。代码检查、构建及 Windows 操作需要相应工具和依赖，窗口操作还受软件界面、焦点和系统环境影响。

Agent“设置 > 能力”管理技能指导、受限数据处理工具及面板，支持验证、启停和回退；技能与扩展不会额外授予权限。“设置 > 改造 Mio”需要匹配源码及开发依赖，先在独立副本完成检查、构建与候选预览，再确认应用本地候选。安装失败或中断有回退处理，主动回退旧版还需其能力与数据兼容。创作连接、工作流、文件权限、浏览器和图片设置位于 Agent“高级设置”。

## 可选组件与语音包

聊天“设置 > 环境与模型”提供检测、安装与验证；FFmpeg 有安装和检测入口，Whisper 安装补齐系统声音采集依赖。文件存在不等于成功加载，地址已配置不等于服务可用。

Genie 运行数据包与 Mio 音色包不随主程序提供。对应“获取与安装”说明允许填写真实 HTTPS 来源或选择匹配的本机离线包，安装前校验内容。**入口和源配置不代表已有官方默认下载地址**；先确认实际发布附件、许可及取得方式。没有可用来源时不能直接在线获取，不要用任意 ZIP 替代指定包。

部分受管可选模型支持卸载，先查看路径和范围再确认；共用环境、自定义素材和个人数据不随模型删除，外部资源在原位置管理。FFmpeg 当前不提供受管卸载入口。聊天“设置 > 微信与QQ”配置相应接入，桌宠与语音在“设置 > 桌宠”中按需配置。

## 从旧版本升级

1. 在聊天“设置 > 数据与隐私”完成完整备份，记下当前数据目录。
2. 0.4.0 发布前，可下载版本仍为 0.3.1；0.2.1 及更早版本可先手动安装 0.3.1。0.4.0 实际发布后再按该 Release 指引升级，沿用原数据，不手动删除 Data。
3. 支持应用内更新的公开版本，可以检查已发布的同通道版本、下载并确认安装。自动下载不等于自动安装，候选文档不代表线上更新清单已经变更。
4. 打开后核对原对话、日记、记忆和模型设置，问题未排除前保留升级前备份。

私人开发版不自动切换到公开版。未配置更新源时会明确提示，使用对应通道安装程序；不要只比较数字版本大小。

## 备份、恢复与换电脑

完整备份用于应用内恢复。换电脑前确认是否包含所需模型权重；没有的需重新安装。API 密钥通过 Windows DPAPI 与当前用户绑定，换电脑或用户后需要重新填写。不要复制正在写入的数据库代替完整备份。Live2D、模型、音色和导入资产遵循各自许可，见[资产与第三方许可](资产与第三方许可.md)。

## 排查问题与验收范围

- 无法聊天：核对 API 地址、Key、模型 ID、额度及真实测试。
- 模型或语音不可用：使用环境中心验证，核对服务、依赖及数据包实际来源。
- 文件预览失败：查看大小、格式提示与成果完整性，必要时在相应软件中打开。
- 代码、命令或电脑任务被拒绝：核对目录、当前权限、窗口授权和依赖；只切换自主执行不会补齐授权。
- 任务结果未知：先查回执及服务实际结果，再按提示恢复。
- 更新失败：保留错误信息，检查网络、磁盘和下载状态，不删除数据目录。

本次相关功能有自动检查、隔离样例及界面验证，不代表所有实际场景已经通过。QQ/微信及创作、生图、视频由用户自测；语音/桌宠本轮免测，未重新验收真实运行；干净 Windows 全量首次安装仍未完成。反馈请提供版本、复现步骤与脱敏诊断，不公开数据库、私人对话、日记、密钥、登录状态、音色或未经处理的日志。
