# 变更记录

本项目采用语义化版本号。尚未正式发布的改动记录在“未发布”部分。

## 0.5.0 - 2026-08-12

### 新增

- 增加数据库迁移账本和启动时自动迁移，升级现有安装时继续使用原 SQLite 数据、人格和运行设置。
- 增加完整备份、校验、下载、导入和恢复；恢复前自动保存当前数据，并阻止路径越界和损坏备份覆盖运行数据。
- 增加五步首次启动状态接口，新安装可先完成角色、称呼、模型、隐私和数据位置确认。
- 增加隐私总控，统一展示并暂停 QQ、联网、主动联系、自动记录、屏幕观察和系统声音等敏感能力。
- 增加对话、模型、首次启动、隐私和完整备份的独立服务与路由，以及对应回归测试。

### 调整

- 将会话和模型逻辑从 Agent 综合路由迁出，保留原有 API 和数据库兼容。
- 根地址统一进入内置 `/agent-app/`；旧日记页面暂时保留兼容，不作为额外产品或公开网站。
- 全新安装默认关闭屏幕观察、系统声音、主动联系、联网和自动记录；已有配置不会被重置。
- 无模型配置时启动接口返回空模型状态和明确提示，不再以 500 阻断首次启动向导。
- 补充隐私说明、首次启动与迁移说明、资产许可边界和发布验收矩阵。

### 已知限制

- QQ 登录受腾讯和 NapCat 登录态约束，凭证失效后仍需用户扫码，应用不会绕过平台安全机制。
- DX11、DX12、独占全屏、HDR、双显示器、游戏性能和连续七天自动任务需要对应硬件与长期现场验收。
- 现有仓库历史包含旧敏感信息风险，公开发布应使用无 `.git` 历史的干净源码包；未经明确授权不重写现有 Git 历史。

## 0.3.0 - 2026-08-11

### 新增

- Agent 内可编辑的人格与属性设置。
- 非敏感运行参数的持久化设置，包括上下文、QQ 消息节奏、主动陪伴、自动记录、联网和本地路径。
- Windows DPAPI 保护的自定义模型供应商密钥。
- 发布前安全、资产授权和隐私检查文档。
- 日常聊天增量维护今日状态，并提供手动重新分析入口。
- 附件、图片归档、屏幕回应与屏幕历史保留设置。
- 不带旧 Git 历史、私人数据、音色和个人角色图片的干净源码包生成脚本。

### 调整

- 新安装默认关闭主动消息、联网查询以及自动调用模型的日记和回顾任务。
- 现有安装继续优先使用本地 `数据/运行设置.json`，不覆盖用户选择。
- 开源默认人格改为中性私人伙伴模板，现有本机人格保持不变。

### 已知限制

- 若直接公开现有仓库，仍需处理 Git 历史扫描结果；干净源码包已经排除未确认授权的私人角色图片、音色和训练检查点。
- QQ 登录依赖用户自行安装和登录 NapCat。
