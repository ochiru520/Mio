Mio 是一款在 Windows 上运行的个人 AI 应用。你可以和她聊天、整理生活记录，也可以在 Agent 中处理资料、文件、代码和创作任务。

聊天与 Agent 共用模型、人格、主题和本地数据；各自专属的设置分别保留。你可以更换模型供应商，调整称呼和表达，使用自己的头像与图片，让她逐渐成为符合你习惯的伙伴。

## Mio 能做什么

| 场景 | 你可以用她做什么 |
|---|---|
| 日常聊天 | 管理多个会话，切换已接入模型，发送图片或文件，查看用量和模型提供的公开分析。 |
| 记忆与生活记录 | 查看记忆来源，编辑、确认或停用记忆；整理每日回顾、周记和月记，查看与恢复记录版本。 |
| 工作与代码 | 阅读资料，生成文稿，处理文件；在授权范围内修改项目代码、查看差异、运行终端命令和测试。 |
| 学习 | 围绕项目资料解释概念、整理笔记、出题和反馈，保留来源与学习记录。 |
| 生图与创作 | 连接你配置的生成服务或 ComfyUI 工作流，使用参考资料和图片，跟踪异步任务并归档成果。 |
| 项目与成果 | 创建或选择本机文件夹，组织项目内的会话、资料、任务和成果，回看来源及版本。 |
| 定时任务 | 建立计划，查看任务状态和执行结果；实际执行仍需要应用与相应服务可用。 |
| 电脑操作 | 观察和操作已授权的 Windows 窗口，结合文件与终端工具处理任务。 |
| 扩展与改造 | 管理版本化技能指导和受限工具/面板；具备匹配源码及开发依赖时，在独立副本中修改、检查、构建并预览 Mio 候选。 |
| 可选陪伴能力 | 配置语音、Live2D 桌宠、QQ/微信及屏幕或系统声音观察，按需要启用。 |

### 任务可以继续，成果可以回看

- **持续任务**：查看进展、追加要求，停止或恢复任务；长任务保留摘要与完整历史回读。
- **文件侧栏**：浏览图片、文本和支持的 Office 内容；Office 预览不完整还原原始排版、动画或图表，也不重算 Excel 公式。
- **上下文与用量**：区分当前上下文估算和累计用量，模型提供公开分析时可展示；没有提供时不会编造。
- **断线核对**：恢复时核对原请求状态，结果未知的写操作不会自动重复执行。

## 开始使用

### 1. 选择下载包并安装

从 [v0.4.0 发布页](https://github.com/ochiru520/Mio/releases/tag/v0.4.0) 下载 `Mio-0.4.0-Windows-x64-Setup.exe`，可使用旁边的 SHA-256 文件核对下载内容。普通用户不需要自行安装 Python 或 Node.js。

主程序、Genie 引擎和 Mio 音色分别提供，按需要单独下载。只使用文字聊天与 Agent 时，下载安装器即可；需要本地语音时，再下载引擎包和音色包。

三个独立文件可通过 [百度网盘国内下载](https://pan.baidu.com/s/1mbT21ul6g1MQEY346F_7HA?pwd=hm75)，提取码：`hm75` 按需获取；GitHub也提供各自附件、源码与版本说明。网盘可能要求登录或客户端，下载速度取决于账号和网络。

主要验证环境为 Windows 11 x64。桌面窗口需要 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。安装器目前没有 Windows Authenticode 代码签名。

### 2. 接入模型

在首次向导或“设置 → 模型与 API”填写供应商地址、API Key 和模型。先试一次普通对话，再根据需要配置工具、项目及可选组件。

云端模型需要你自己的 API，费用由供应商收取；安装 Mio 不包含模型额度。使用工作、生图或其他工具前，确认对应环境已经就绪。

### 3. 选择你的使用方式

- **聊天**：日常交流、记忆和生活记录。
- **工作**：资料、文稿、项目文件、代码与电脑任务。
- **学习**：围绕指定资料学习、练习与回顾。
- **生图**：使用已接入的生成服务或工作流。

想处理项目时，选择已有文件夹或创建新文件夹，再在项目内新建对话。生成服务、模型权重和语音数据等按需准备，不随主程序全部内置。

## 语音组件在哪里获取

**Genie 引擎和 Mio 音色是两个独立 ZIP，分别下载、分别安装。** 网盘保留中文包名，将它们放在原安装器旁可自动识别；GitHub附件使用英文文件名、内容校验相同，可在“设置 → 环境与模型”分别选择对应离线包。先安装引擎，再安装音色，两个数据 ZIP 不需要自行解压。

两个独立语音包和各自 SHA-256 已补入 v0.4.0 发布附件。已安装的 v0.4.0 可选择离线 ZIP 安装，或在获取配置中保存下面的实际 HTTPS 地址；本次补附件不重打主安装器。

| 组件 | 用途 | 当前获取情况 |
|---|---|---|
| Genie 本地语音运行引擎 | 运行本地语音合成，需要 Genie 软件及配套运行数据。 | [GitHub 独立下载](https://github.com/ochiru520/Mio/releases/download/v0.4.0/Mio-Genie-Runtime-v1.zip) · [SHA-256](https://github.com/ochiru520/Mio/releases/download/v0.4.0/Mio-Genie-Runtime-v1.zip.sha256.txt) · 也可使用上面的百度网盘入口。 |
| Mio 本地原声音色 | 提供 Mio 音色模型及参考素材，需要 Genie 引擎配合使用。 | [GitHub 独立下载](https://github.com/ochiru520/Mio/releases/download/v0.4.0/Mio-Native-Voice-mio-v1.zip) · [SHA-256](https://github.com/ochiru520/Mio/releases/download/v0.4.0/Mio-Native-Voice-mio-v1.zip.sha256.txt) · 也可使用上面的百度网盘入口。 |

Genie 的上游官方入口：[Genie-TTS 项目与教程](https://github.com/High-Logic/Genie-TTS/blob/v2.0.2/README_zh.md)、[GenieData 运行数据](https://huggingface.co/High-Logic/Genie/tree/main/GenieData)、[genie-tts 2.0.2 软件包](https://pypi.org/project/genie-tts/2.0.2/)。这些来源提供的是上游软件或资源，**不是 Mio 的两个定制安装 ZIP**。Mio 音色不在这些上游入口中。

两个 ZIP 包含语音数据，**不是完全离线运行环境**：首次安装 Genie 仍需联网准备 Python 和运行依赖，安装脚本优先使用国内镜像。安装程序会核对包名、大小和 SHA-256。软件也可保存实际 HTTPS 下载地址，但地址必须指向与校验清单匹配的包，不能拿任意上游压缩包替代。

两个包的文件名相似，但作用不同。安装 `genie-tts` Python 软件包不会自动得到 Mio 音色，也不能代替上述配套数据。引擎代码、模型权重和音色素材的许可分别适用，Mio 的 MIT 许可不自动覆盖它们。

尚未准备语音组件时，可以先使用文字聊天和 Agent。

获取状态、上游资源与离线安装的区别见 [语音组件获取指南](私人AI日记系统/文档/语音组件获取指南.md)。

## 数据、权限与使用边界

- **本地保存**：会话、记忆、记录和项目数据存放在你选择的本机目录，支持备份恢复。完整备份不代表密钥能跨 Windows 用户自动恢复。
- **按服务发送请求**：使用云端模型、搜索或视觉时，所需内容会发送给你选择的服务。“本地保存”不代表全部离线。
- **按授权执行**：文件、终端和窗口工具受实际权限约束；“自主执行”不会自行增加权限。
- **终端环境**：本机命令运行不是系统沙箱；可选隔离终端需要 Docker 可用。Windows 操作效果受软件界面、焦点与系统环境影响。
- **结果核对**：摘要可能遗漏细节，费用展示依赖供应商返回的信息。重要成果仍应结合原文、文件内容与实际执行结果判断。

公开源码不包含作者的私人对话、日记、人格原文、API 密钥、QQ 登录态、训练音频或私人模型。

## 开发与项目结构

Mio 使用 Vue 3 / Vite 构建界面，Python / FastAPI 运行后端，SQLite 保存数据；Windows 启动器负责桌面窗口，独立更新器处理签名清单、安装与恢复。

```text
Mio/
├─ 澪Agent应用/
│  ├─ src/                 界面、业务状态、接口和样式
│  ├─ desktop/             桌面启动、窗口与更新
│  ├─ scripts/             构建、验收和组件安装
│  └─ live2d-desktop/       可选桌宠进程
├─ 私人AI日记系统/
│  ├─ backend/app/         模型、会话、Agent、工具与存储
│  ├─ backend/tests/       后端测试
│  └─ 文档/                使用、架构、隐私和资产说明
└─ docs/image/             项目标识与软件截图
```

两个中文子目录用于现有构建和路径兼容。目录条目多少不代表功能多少；公开发行与私人开发使用独立版本通道。

从源码运行、检查命令与开发约定见 [参与贡献](CONTRIBUTING.md) 和 [代码结构与模块边界](私人AI日记系统/文档/代码结构与模块边界.md)。请使用与你运行版本匹配的源码与依赖。
